## CitySync


# 1. Project Overview
This project, Intelligent Urban Mobility Analysis, aims to build a machine learning model to forecast taxi demand in NYC. We predict the number of trips originating from specific zones during a given time block.

# 2. Technical Details
Problem Type: Regression/Time-Series Forecasting

Mandatory Model: Linear Regression (as baseline)

Bonus Model(s): Random Forest Regressor (for performance comparison), use XGBoost

Technology Stack: Python 3.0, Pandas, NumPy, Scikit-learn, Matplotlib.

# 3. Data Source & Preparation
Source: NYC Taxi and Limousine Commission (TLC) Trip Record Data.

Required Files: Monthly yellow and green tripdata parquet files and the taxi_zone_lookup.csv table.


# 4. Execution & Structure
Setup: Use the shared requirements.txt file to set up your Python environment.

Main Notebook: The primary code is in CitySync.ipynb (or Colab equivalent).

Run Sequence: Run all cells in the notebook sequentially to reproduce the analysis, model training, and performance comparison.
